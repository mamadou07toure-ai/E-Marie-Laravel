# PARTIE 1 — ESPACE CITOYEN

---

## 1. Créer un compte

### Accès
Rendez-vous sur la page d'accueil du portail et cliquez sur **"S'inscrire"**.

### Étapes

1. Remplissez le formulaire d'inscription :
   - **Prénom** *(obligatoire)*
   - **Nom** *(obligatoire)*
   - **Adresse e-mail** *(obligatoire — sera votre identifiant de connexion)*
   - **Numéro de téléphone** *(obligatoire)*
   - **Mot de passe** *(minimum 8 caractères)*
   - **Confirmation du mot de passe**

2. Cliquez sur **"Créer mon compte"**.

3. Vous êtes automatiquement connecté et redirigé vers votre tableau de bord.

> **Note** : L'adresse e-mail doit être unique. Si un compte existe déjà avec cette adresse, un message d'erreur s'affiche.

---

## 2. Se connecter

### Accès
Cliquez sur **"Se connecter"** depuis la page d'accueil, ou accédez directement à `/connexion`.

### Étapes

1. Saisissez votre **adresse e-mail** et votre **mot de passe**.
2. Cliquez sur **"Se connecter"**.
3. Vous êtes redirigé vers votre tableau de bord citoyen.

### Mot de passe oublié

1. Cliquez sur **"Mot de passe oublié ?"**.
2. Saisissez votre adresse e-mail.
3. Un lien de réinitialisation vous est envoyé par e-mail (valide 60 minutes).
4. Cliquez sur le lien, saisissez votre nouveau mot de passe, confirmez.

---

## 3. Tableau de bord citoyen

Le tableau de bord est votre page principale. Il affiche :

| Zone | Contenu |
|------|---------|
| **Statistiques** | Nombre de dossiers en cours, en attente, validés |
| **Dossiers récents** | Vos 5 dernières demandes avec leur statut |
| **Accès rapide** | Boutons : Nouvelle demande, Mes dossiers, Messages |

### Signification des statuts

| Statut | Couleur | Signification |
|--------|---------|---------------|
| **En attente** | Gris | Votre demande est enregistrée, aucun agent ne l'a encore prise en charge |
| **En cours** | Bleu | Un agent traite votre dossier |
| **Document manquant** | Orange | L'agent vous demande une pièce complémentaire |
| **Validé** | Vert | Votre demande est approuvée, le document est disponible |
| **Rejeté** | Rouge | Votre demande a été refusée (voir le motif dans le dossier) |

## 4. Soumettre une nouvelle demande

### Accès
Cliquez sur **"Nouvelle demande"** dans la navigation ou sur le bouton du tableau de bord.

### Étapes

#### Étape 1 — Choisir le type de demande

Sélectionnez le service souhaité parmi :
- **Acte de Naissance** — Extrait ou copie intégrale d'acte de naissance
- **Certificat de Résidence** — Attestation de domicile
- **Certificat de Mariage** — Extrait d'acte de mariage
- **Légalisation de Document** — Authentification d'un document officiel

#### Étape 2 — Choisir la priorité

| Priorité | Quand l'utiliser |
|----------|-----------------|
| **Normale** | Délai standard |
| **Haute** | Besoin sous 48h |
| **Urgente** | Besoin immédiat (mise en évidence pour l'agent) |

#### Étape 3 — Remplir le formulaire

Le formulaire s'adapte automatiquement au type choisi.

**Pour un Acte de Naissance**, renseignez :
- Nom et prénoms du titulaire
- Date et lieu de naissance
- Genre (M / F)
- Informations du père (nom, prénom, profession)
- Informations de la mère (nom, prénom, profession)
- Motif de la demande
- Nombre de copies souhaitées

**Pour un Certificat de Résidence**, renseignez :
- Nom et prénoms
- Adresse complète
- Quartier / Commune
- Durée de résidence
- Motif de la demande

**Pour un Certificat de Mariage**, renseignez :
- Informations de l'époux (nom, prénom, date et lieu de naissance)
- Informations de l'épouse (nom, prénom, date et lieu de naissance)
- Date et lieu du mariage
- Numéro d'acte de mariage *(si disponible)*
- Motif

**Pour une Légalisation de Document**, renseignez :
- Nom et prénoms du demandeur
- Type de document à légaliser
- Description du document
- Langue du document
- Pays de destination
- Usage prévu

#### Étape 4 — Joindre les pièces justificatives *(optionnel)*

Cliquez sur la zone de dépôt ou glissez-déposez vos fichiers.
- Formats acceptés : **PDF, JPG, JPEG, PNG**
- Taille maximale : **10 Mo par fichier**

#### Étape 5 — Soumettre

Cliquez sur **"Lancer la demande"**.

Un message de confirmation s'affiche avec votre **numéro de dossier** (ex : `MAI-2026-00042`). Conservez ce numéro.

---

## 5. Suivre ses dossiers

### Accès
Cliquez sur **"Mes dossiers"** dans la navigation.

### Fonctionnalités

- **Liste complète** de toutes vos demandes, de la plus récente à la plus ancienne
- **Badge de statut** coloré pour chaque dossier
- **Filtrage** par statut (tous, en attente, en cours, validés, rejetés)
- Cliquez sur la **flèche →** d'un dossier pour voir son détail

---

## 6. Consulter un dossier en détail

### Contenu de la page

| Section | Description |
|---------|-------------|
| **En-tête** | Numéro de dossier, statut, type, date de dépôt |
| **Informations** | Type de service, motif, description |
| **Alerte document manquant** | Bandeau orange indiquant la pièce à fournir |
| **Pièces jointes** | Documents uploadés, téléchargeables |
| **Agent en charge** | Nom de l'agent assigné + bouton "Envoyer un message" |
| **Suivi du traitement** | Chronologie des étapes avec dates et commentaires |

### Que faire si un document est manquant ?

Si un bandeau orange **"Document manquant"** s'affiche :
1. Lisez attentivement la pièce demandée par l'agent
2. Cliquez sur **"Envoyer un message"** pour contacter l'agent
3. Transmettez la pièce via la messagerie ou en personne à la mairie

---

## 7. Télécharger son document officiel

### Condition

Le bouton de téléchargement n'apparaît que lorsque le dossier est en statut **"Validé"**.

### Étapes

1. Ouvrez votre dossier validé depuis **"Mes dossiers"**
2. Cliquez sur le bouton vert **"Télécharger Document Officiel"** en haut à droite
3. Le PDF se génère automatiquement et se télécharge dans votre dossier Téléchargements
4. Le fichier est nommé : `Document_MAI-2026-XXXXX.pdf`

> **Note** : Ce bouton n'apparaît que si l'administration a configuré un modèle pour ce type de demande. Dans le cas contraire, le bouton "Télécharger Document Officiel" classique reste disponible.

---

## 8. Contacter l'agent en charge

### Depuis la page du dossier

1. Ouvrez votre dossier
2. Dans la section **"Agent en charge"** (colonne de droite), cliquez sur **"Envoyer un message"**
3. La messagerie s'ouvre directement avec l'agent assigné

### Depuis la messagerie

Naviguez vers **"Messages"** dans la sidebar pour accéder à toutes vos conversations.

---

## 9. Messagerie citoyen

### Accès
Cliquez sur **"Messages"** dans la navigation latérale.

### Interface

- **Colonne gauche** : liste de vos conversations avec les agents
- **Colonne droite** : fenêtre de chat avec l'agent sélectionné
- Un badge rouge indique le nombre de messages non lus

### Envoyer un message

1. Sélectionnez une conversation (ou démarrez-en une depuis un dossier)
2. Tapez votre message dans le champ en bas
3. Appuyez sur **Entrée** ou cliquez sur le bouton d'envoi ✈

### Fonctionnalités

- Les messages se rafraîchissent automatiquement toutes les 5 secondes
- ✓✓ bleu = message lu par l'agent
- Vous pouvez **modifier** un message envoyé (icône crayon au survol)
- Vous pouvez **supprimer** un message envoyé (icône poubelle au survol)

---

## 10. Gérer son profil

### Accès
Cliquez sur votre **prénom** en haut à droite ou sur **"Paramètres"** dans la navigation.

### Modifications possibles

| Section | Champs modifiables |
|---------|--------------------|
| **Informations personnelles** | Prénom, Nom, Téléphone |
| **Sécurité** | Ancien mot de passe → Nouveau mot de passe |
| **Avatar** | Photo de profil (JPG, PNG, max 2 Mo) |

Cliquez sur **"Sauvegarder"** après chaque modification.

### Accès

## 12. Tableau de bord agent

Le tableau de bord affiche :

| Indicateur | Description |
|-----------|-------------|
| **À traiter** | Vos dossiers en cours assignés |
| **Traités** | Dossiers que vous avez validés ou rejetés |
| **Total assignés** | Nombre total de dossiers qui vous ont été assignés |
| **En attente (global)** | Tous les dossiers non encore assignés dans le système |

La section **"Dernières demandes"** liste les 10 dossiers les plus récents de tous les agents — permet de voir la charge globale.

---

## 13. Liste de tous les dossiers

### Accès
Cliquez sur **"Tous les dossiers"** dans la navigation.

### Fonctionnalités

- Vue complète de tous les dossiers du système (tous agents)
- **Barre de recherche** : par numéro de dossier, nom du citoyen, type
- **Filtre par statut** : Tous, En attente, En cours, Pièce manquante, Validés, Rejetés
- **Colonne "Agent assigné"** : indique qui traite chaque dossier (ou badge "Non assigné")
- **Bouton "Prendre en charge"** sur les dossiers non assignés
- **Bouton →** pour ouvrir le détail d'un dossier

### Mes assignations
Cliquez sur **"Mes assignations"** pour ne voir que les dossiers qui vous sont assignés.

---

## 14. Prendre en charge un dossier

### Depuis la liste

1. Repérez un dossier avec le badge **"Non assigné"**
2. Cliquez sur le bouton bleu **"Prendre en charge"**
3. Le dossier vous est immédiatement assigné, le statut passe à **"En cours"**

### Depuis le détail du dossier

1. Ouvrez un dossier non assigné
2. Dans le **Panneau de décision** (colonne droite), cliquez sur **"Prendre en charge"**

> **Important** : Un dossier déjà assigné à un autre agent ne peut pas être repris. Le bouton "Prendre en charge" n'apparaît pas dans ce cas.

---

## 15. Traiter un dossier

### Accéder au dossier

1. Cliquez sur **→** dans la liste ou cherchez par numéro de dossier
2. La page affiche toutes les informations du citoyen, les pièces jointes et l'historique

### Vérifier les informations

| Section | Contenu |
|---------|---------|
| **Données structurées** | Formulaire rempli par le citoyen (noms, dates, adresses…) |
| **Documents justificatifs** | Pièces jointes téléchargeables |
| **Traçabilité** | Historique complet des actions sur le dossier |
| **Notes internes** | Commentaires des agents (invisibles pour le citoyen) |

### Valider un dossier

1. Vérifiez que toutes les informations sont conformes
2. Dans le **Panneau de décision** (colonne droite), cliquez sur **"Valider le dossier"** (bouton vert)
3. Le statut passe à **"Validé"**, le dossier est clôturé
4. Le citoyen peut désormais télécharger son document officiel

---

## 16. Demander une pièce manquante

Utilisez cette action quand le citoyen n'a pas fourni un document nécessaire.

### Étapes

1. Dans le **Panneau de décision**, cliquez sur **"Actions"** (bouton en haut à droite)
2. Cliquez sur **"Demander pièce manquante"**
3. Décrivez précisément la pièce requise (ex : *"Copie de la carte nationale d'identité en cours de validité"*)
4. Cliquez sur **"Notifier le citoyen"**

### Effets

- Le statut passe à **"Document manquant"**
- Le citoyen reçoit une notification
- Sur la page du dossier du citoyen, un **bandeau orange** affiche la pièce demandée
- L'historique est mis à jour avec votre commentaire

### Reprendre le traitement

Quand le citoyen fournit la pièce, repassez le statut à **"En cours"** depuis le menu Actions.

---

## 17. Rejeter un dossier

Utilisez cette action uniquement quand le dossier ne peut pas être traité favorablement.

### Étapes

1. Dans le **Panneau de décision**, cliquez sur **"Rejeter / Refuser"** (bouton rouge)
2. Un formulaire s'affiche : **saisissez obligatoirement le motif du rejet**
   - Soyez précis et factuel (ex : *"Acte de naissance non conforme — la date ne correspond pas aux registres"*)
3. Cliquez sur **"Confirmer"**

### Effets

- Le statut passe à **"Rejeté"**, le dossier est clôturé
- Le motif est enregistré et visible par le citoyen sur son dossier
- Le citoyen peut, si nécessaire, soumettre une nouvelle demande corrigée

> **Attention** : Le rejet est définitif. Le dossier ne peut plus être modifié après clôture.

---

## 18. Ajouter une note interne

Les notes internes sont des commentaires **visibles uniquement par les agents** — le citoyen n'y a pas accès.

### Utilisation recommandée

- Indiquer des vérifications en cours
- Signaler une anomalie à un collègue
- Laisser un contexte pour un agent qui reprendrait le dossier

### Étapes

1. Faites défiler jusqu'à la section **"Notes internes"** en bas de la page
2. Saisissez votre note dans la zone de texte
3. Cliquez sur **"Ajouter la note"**

La note s'affiche avec votre prénom et l'horodatage. Les notes s'accumulent sans jamais être supprimées.

---

## 19. Messagerie agent

### Accès
Cliquez sur **"Messages"** dans la navigation. Un badge rouge indique les messages non lus.

### Interface

- **Colonne gauche** : liste des conversations avec les citoyens (nom, dernier message, heure, compteur non lus)
- **Colonne droite** : fenêtre de chat

### Répondre à un citoyen

1. Cliquez sur la conversation du citoyen
2. Tapez votre réponse dans le champ en bas
3. Appuyez sur **Entrée** ou cliquez sur **✈**

### Fonctionnalités

- Polling automatique toutes les **5 secondes** : les nouveaux messages s'affichent sans recharger la page
- Messages en **noir** = envoyés par vous
- Messages en **blanc** = envoyés par le citoyen
- ✓✓ bleu = message lu par le destinataire
- Survolez vos messages pour accéder à **Modifier** (✏) ou **Supprimer** (🗑)

## Résolution des problèmes courants

| Problème | Solution |
|----------|----------|
| *"Je ne vois pas le bouton Télécharger"* | Le dossier doit être au statut **"Validé"** |
| *"Je ne peux pas prendre en charge ce dossier"* | Il est déjà assigné à un autre agent |
| *"Impossible de charger les conversations"* | Vérifiez votre connexion internet et rechargez la page |
| *"Mes fichiers sont refusés"* | Seuls les formats PDF, JPG, PNG sont acceptés (max 10 Mo) |
| *"Le formulaire affiche une erreur"* | Vérifiez que tous les champs obligatoires (*) sont remplis |
| *"Ma session expire"* | Reconnectez-vous — les sessions durent 2 heures d'inactivité |
